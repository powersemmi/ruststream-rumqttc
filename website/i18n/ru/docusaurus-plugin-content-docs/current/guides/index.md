# Руководства

Крейт `ruststream-rumqttc` реализует брокер MQTT 5 для [RustStream](https://powersemmi.github.io/ruststream/latest/ru/).
Он построен на клиенте [rumqttc](https://docs.rs/rumqttc). Руководства проводят сервис на MQTT
от установки до промышленной эксплуатации.
